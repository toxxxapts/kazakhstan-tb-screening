# Скрининг туберкулёза и очередь на чтение снимков в Астане

Проект Serik Togzhan для Городской поликлиники №15 города Астана. Описание, результаты и источники находятся в REPORT.md. Сводные данные поликлиники можно внести в local_shift_template.csv. Результаты в архиве получены на открытых снимках и в симуляции.

## 1. Симуляция очереди

Нужен только Python 3.10+. Из папки проекта запустите:

```bash
python simulate.py
```

Команда воспроизводит 600 прогонов в results/runs.csv и шесть сводных строк в results/summary.csv. Каждая пара политик получает те же снимки, метки, моменты поступления и длительности чтения.

## 2. Эксперимент на публичных снимках

Установите зависимости, скачайте из каталога NLM PNG-файлы Shenzhen и Montgomery, затем укажите две папки. Поддерживаются вложенные папки и оригинальные имена CHNCXR_*_0.png / CHNCXR_*_1.png и MCUCXR_*_0.png / MCUCXR_*_1.png.

```bash
python -m pip install -r requirements-images.txt
python images.py data/Shenzhen data/Montgomery
```

Результаты записываются в image_results/metrics.json и image_results/predictions.csv. Порог подбирается на валидационной части Shenzhen. Montgomery используется только для независимой проверки. Для модели с реальными снимками проверьте правила использования данных NLM и укажите исходную публикацию.

В results/public_pilot сохранён пробный прогон на 80 реальных открытых снимках. Для воспроизведения скачайте файлы из sample_files.txt по каталогам Shenzhen и Montgomery. Изображения в архив не включены.

Два эксперимента отвечают на разные вопросы. Модель на снимках оценивает перенос между публичными наборами. Симуляция показывает, что будет с очередью при заданных характеристиках воображаемой модели. Настройки симуляции заданы заранее, без подстановки метрик публичных наборов. Прототип предназначен для исследовательских экспериментов с открытыми наборами и синтетической очередью.

[Каталог изображений NLM](https://data.lhncbc.nlm.nih.gov/public/Tuberculosis-Chest-X-ray-Datasets/index.html)
